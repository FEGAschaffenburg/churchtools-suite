## ✅ Test-Checkliste

### Funktionalität
- [ ] Alle Shortcodes rendern ohne Fehler
- [ ] Events werden korrekt angezeigt
- [ ] Kalenderfilter funktionieren
- [ ] Datumsfilter funktionieren
- [ ] Services werden angezeigt (wo aktiviert)

### Layout & Design
- [ ] Responsive Design auf Mobile
- [ ] Keine Layout-Breaks
- [ ] Farben konsistent
- [ ] Schriften lesbar
- [ ] Abstände harmonisch

### Performance
- [ ] Ladezeiten akzeptabel
- [ ] Keine JavaScript-Fehler in Console
- [ ] Keine PHP-Fehler in Debug-Log
- [ ] Bilder laden korrekt

### Interaktion
- [ ] Slider autoplay funktioniert
- [ ] Carousel Navigation funktioniert
- [ ] Modal öffnet/schließt
- [ ] Search funktioniert
- [ ] Map-Marker klickbar

### Edge Cases
- [ ] Keine Events vorhanden → Empty State
- [ ] Ungültige Kalender-ID → Fehlerbehandlung
- [ ] Sehr lange Titel → Textumbruch
- [ ] Sehr viele Events → Pagination
- [ ] Keine Services → Kein Layout-Break
