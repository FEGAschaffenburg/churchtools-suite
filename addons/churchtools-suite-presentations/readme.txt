Erstellt Präsentationsseiten für ChurchTools-Termine und vorhandene Suite-Ansichten.

== Beschreibung ==

Presentations ist ein eigenständiges Addon für ChurchTools Integration Suite. Das Hauptplugin bleibt erforderlich; das Demo-Plugin und das Demo-Theme sind optional.

== Voraussetzungen ==

- WordPress >= 6.0
- PHP >= 8.0
- ChurchTools Integration Suite >= 1.3.0.6

== Installation ==

1. ChurchTools Integration Suite installieren und aktivieren.
2. Die ZIP-Datei aus dem [GitHub-Repository](https://github.com/FEGAschaffenburg/churchtools-suite-presentations/releases) herunterladen.
3. Unter Plugins -> Installieren -> Plugin hochladen installieren.
4. Das Addon aktivieren.
5. Im ChurchTools-Menü die Präsentationsseite konfigurieren.

== Verwendung ==

- Präsentationsseite anlegen oder auswählen.
- Events und gewünschte Ansichten konfigurieren.
- Die Seite veröffentlichen und auf dem Zielbildschirm öffnen.

== Updates ==

Das Addon wird unabhängig vom Hauptplugin über sein eigenes GitHub-Repository aktualisiert.

== FAQ ==

= Ist das Demo-Plugin erforderlich? =

Nein. Das Demo-Plugin und das Demo-Theme werden nur für die Dokumentations-/Demo-Seite benötigt.
